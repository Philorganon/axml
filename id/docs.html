Referensi Lengkap 4.0

Selamat datang di panduan utama untuk Audio XML (AXML). Spesifikasi ini mendefinisikan format berbasis teks yang kuat untuk sintesis dan komposisi musik di web.

Apakah Anda seorang desainer suara yang memahat synth melalui kode atau seorang komposer yang membangun aransemen kompleks, AXML memberi Anda kendali presisi atas setiap frekuensi dan ketukan.

account_tree Hierarki Root

File AXML yang valid harus mengikuti urutan elemen yang tepat ini. Engine memprosesnya secara berurutan untuk membangun graf audio.

<?xml version="1.0" encoding="UTF-8"?>
<axml version="1.0">
  <metadata> ... </metadata>
  <instruments> ... </instruments>
  <patterns> ... </patterns>
  <tracks> ... </tracks>
</axml>

info Metadata Global

Metadata mendefinisikan konteks proyek. tempo sangat penting karena mendefinisikan bagaimana beat diterjemahkan ke detik.

Elemen Deskripsi
<title> Nama tampilan proyek.
<artist> Pembuat proyek atau desainer suara.
<tempo> Beats Per Minute (60.0 - 250.0). Rata-rata: 120.
<key> Nada dasar musik (misalnya, C, Am, F#m).
<time-signature> Struktur ritme (misalnya, 4/4, 3/4). 
<metadata>
  <title>Cyberpunk City</title>
  <artist>AXML Master</artist>
  <tempo>128</tempo>
  <key>Am</key>
</metadata>

waves Tipe Osilator

Atribut type pada <instrument> menentukan bentuk gelombang dasar. AXML saat ini mendukung 11 tipe berbeda:

Nama Tipe Gelombang Matematis / Model Fisik
sine Gelombang sinus murni (Hanya frekuensi fundamental).
square Gelombang kotak (Kaya akan harmonik ganjil).
sawtooth Gelombang gigi gergaji (Semua harmonik, sangat terang).
triangle Gelombang segitiga (Harmonik lembut).
kick Model fisik: Sapuan sinus + Peluruhan eksponensial cepat.
snare Model fisik: White noise + Lowpass filter pada 1.2kHz.
hihat Model fisik: White noise + Highpass filter pada 8kHz.

gesture Envelope ADSR

Envelope volume sangat penting untuk mendefinisikan "bentuk" suara. Semua nilai dalam detik, kecuali sustain (0.0 hingga 1.0).

Atribut Nama Lengkap Perilaku
attack Attack Time Detik untuk mencapai volume puncak.
decay Decay Time Detik untuk turun ke level sustain.
sustain Sustain Level Faktor volume (0-1) yang ditahan selama nada aktif.
release Release Time Detik untuk memudar ke hening setelah nada berakhir.

music_note Cara Membuat Musik Sendiri dari Nol

Membuat musik di AXML sangat mudah jika Anda memahami 4 langkah dasar komposisi deklaratif:

  1. Tentukan Metadata: Atur <tempo> (BPM), <key> (nada dasar misalnya C, Am), dan <scale> di dalam tag <metadata>.
  2. Rancang Instrumen: Definisikan synthesizer lead, bass, dan drum (kick, snare, hihat) pada <instruments> dengan memilih tipe gelombang (sawtooth, square, sine) dan efek ADSR.
  3. Tulis Partitur Track: Buat alur musik di <tracks>. Gunakan <note pitch="C4" start="0" duration="q"/> untuk melodi monophonic dan <chord> untuk harmoni akor.
  4. Susun Aransemen: Bagilah lagu ke dalam struktur baku: Intro (0-16 beat) → Verse → Drop/Chorus (energi maksimal) → Outro.

Tips Pro: Gunakan metrum 4/4 standar di mana 1 bar terdiri dari 4 ketukan (beat 0, 1, 2, 3). Kick drum ditaruh pada setiap ketukan genap untuk beat 4-on-the-floor khas house/EDM.

psychology Panduan Komposisi AI (LLM Prompting)

AXML adalah bahasa standar yang sempurna untuk AI generative audio. Anda bisa meminta ChatGPT, Claude, atau Gemini untuk mengarang lagu utuh dengan memberikan prompt berikut:

Buatkan komposisi musik lengkap dalam format Audio XML (AXML 4.0).
Aturan:
- Gunakan root <axml version="4.0">
- Metadata tempo 124 BPM, Key Am
- Rancang instrumen: kick, snare, hihat, synth bass (sawtooth), lead melody (square/saw)
- Susun tracks dengan drum 4-on-the-floor, bassline oktaf 1-2, dan lead oktaf 4-5
- Sinkronkan start dan duration dalam birama 4/4

Salin hasil XML dari AI langsung ke editor AXML Studio dan tekan Space untuk langsung mendengarkan musiknya!

keyboard Shortcut Keyboard Studio 4.0

Percepat workflow produksi musik Anda di Studio:

  • Space : Putar / Hentikan Audio (Play / Stop)
  • Ctrl + Enter : Kompilasi & Playback Audio
  • Ctrl + S : Simpan Proyek ke Penyimpanan Lokal
  • Ctrl + Alt + F : Format Otomatis Indentasi XML (2 Spasi)
  • Ctrl + B : Buka / Tutup Laci Kiri (Library & Presets)
  • Ctrl + J : Buka / Tutup Laci Bawah (Terminal Diagnostics & Mixer)
  • Tab : Indentasi 2 spasi di editor
