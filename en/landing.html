The standard

A format built for how music is actually made.

Text is the most reviewable, diffable, and automatable interface ever built. AXML treats a composition as a document — not a binary you have to decode.

01 / COMPOSITION
tracks/main-lead.axml

Declarative composition

Instruments, chord polyphony, rhythms, and multi-track sequences as Git-friendly text. Review a track like a pull request.

02 / AI-NATIVE
PROMPT→ AXML→ SCHEMA→ AUDIO

Machine-writable, human-readable

A strict, versioned schema that LLMs can generate, validate, and diff. No hallucinated binaries. No opaque project files.

Syntax

Read it, diff it, hear it.

Every element maps to a DSP parameter. There is no hidden state and no proprietary project file — just a document that renders the same way every time.

lofi_chill.axml
AXML 4.0 
<?xml version="1.0" encoding="UTF-8"?><axml version="4.0">  <metadata>    <title>Lofi Chill</title>    <tempo>85</tempo>    <key>Gm</key>  </metadata>  <instruments>    <instrument id="keys" type="triangle"      volume="0.7" cutoff="1600"      resonance="4" delay="0.3"/>  </instruments>  <tracks>    <track instrument="keys" name="Keys">      <note pitch="G3" start="0" duration="1"/>      <note pitch="Bb3" start="1" duration="1"/>      <note pitch="D4" start="2" duration="1"/>      <note pitch="F4" start="3" duration="1"/>    </track>  </tracks></axml>
